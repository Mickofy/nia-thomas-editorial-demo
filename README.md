# NIA THOMAS — Unofficial Editorial Redesign Concept

This independent, speculative Shopify storefront redesign is a portfolio demonstration prepared for a freelance project application. It is **not affiliated with, endorsed by, or commissioned by NIA THOMAS**.

The prototype illustrates homepage, collection, and product presentation concepts. Cart, pricing, product filtering, and newsletter interactions are demonstrations only and are **not connected to the live Shopify store**. Fashion imagery and NIA THOMAS references remain the respective owner's intellectual property and are loaded from the public storefront; no media files are redistributed in this repository.

To view locally, open `index.html` in a browser with an internet connection. The published Cloudflare Pages project is configured with this directory as its root.

Live demo: https://nia-thomas-editorial-concept.pages.dev/
